CẨM NANG VẬN HÀNH DỰ ÁN

Best Practices & Quy Trình Văn Thư Tự Động

Văn phòng Đăng ký Đất đai - Chi nhánh số 23

Nhấn "Tiếp" hoặc dùng phím mũi tên để bắt đầu

1. Cài đặt & Khởi tạo (Không cần biết Code)

Hệ thống sẽ tự động cấu hình 100% chỉ với 3 bước đơn giản.

1

Tải Antigravity & Chọn Model

Truy cập antigravity.google tải ứng dụng Antigravity. Đăng nhập và chọn model Gemini 3.1 Pro (Gói Google Pro).

2

Cấp Quyền Tự Động (Full Turbo)

Mở Antigravity. Vào Cài đặt (Settings), bật quyền Auto-approve tool calls để AI tự do chạy mà không cần hỏi bạn mỗi lệnh.

3

Đọc "Câu Thần Chú"

Copy đoạn lệnh dưới đây dán vào khung chat của Antigravity và bấm Enter. Xong! Bạn có thể đi pha ly cà phê.

"Tôi là nhân viên văn phòng mới. Hãy giúp tôi tải (clone) toàn bộ dự án từ GitHub https://github.com/QuanDo610/BinhDuongCN23 về máy. Sau đó, đọc kỹ file Skill.md trong đó để tự động setup toàn bộ môi trường làm việc: khởi tạo venv, cài đặt các thư viện python cần thiết. Cứ tự động chạy, làm xong thì báo cáo cho tôi."

2. Luồng Công Việc (Workflow)

Hệ thống tuân thủ quy trình 1 chiều, bảo vệ dữ liệu gốc tuyệt đối.

flowchart TD A[Nhận Tài Liệu] --> B(Thư mục documents) B --> C{AI Xử Lý} C --> D[Kết quả File DOCX] C --> E[Kết quả File XLSX] C --> F[Cảnh báo Lỗi] D --> G((Trình Ký)) E --> G

Nguyên tắc "Chỉ Đọc"

Tuyệt đối không sửa file trong thư mục `documents`. Mọi chỉnh sửa phải do AI thực hiện và xuất ra `OUTPUT`.

3. Quy Chuẩn Thư Mục

Ba không gian làm việc tách biệt hoàn toàn.

/documents

Đầu Vào (Input)

Nơi chứa dữ liệu thô (Công văn, PDF, Phụ lục). Đây là "kho chứa nguyên liệu".

Quyền: Bỏ file vào, Không sửa/xóa.
/OUTPUT

Đầu Ra (Output)

Nơi AI trả kết quả (Quyết định NĐ30, Báo cáo đối chiếu). "Thành phẩm" nằm ở đây.

Quyền: Lấy file đem in ấn.
/tools

Công Cụ (Code)

Bộ não mã nguồn (Python, JS) giúp tự động hóa. Không dành cho User thông thường.

Quyền: KHÔNG đụng vào.

4. Quy Chuẩn Đặt Tên File

Giúp hệ thống và AI dễ dàng đọc hiểu và tự động dọn dẹp.

Quy tắc Sai Đúng
Không dùng khoảng trắng/dấu Báo cáo tháng 9.docx Bao_cao_thang_9.docx
Quản lý File Nháp Phuong_an_moi_nhat.docx Phuong_an_CN23_v1.docx
Đánh dấu File Chốt Phuong_an_cuoi_cung.docx Phuong_an_CN23_FINAL.docx
Quy chuẩn NĐ30 (Mã_Số_Tríchyếu) QD 45 phan cong nhiem vu.docx QD_45_CN23_Phan_cong_nhiem_vu.docx

5. Kỹ Năng Giao Tiếp Với AI

Cách "ra lệnh" chuẩn xác để AI làm việc hiệu quả nhất.

Công thức vàng:

[Hành động] + [File Nguồn] + [Định dạng Đích]
Sinh văn bản NĐ30

"Hãy đọc file Bang_doi_chieu.xlsx trong documents và sinh ra Quyết định phân công ra thư mục OUTPUT."

Rà soát & Đánh giá (Audit)

"Hãy rà soát chéo file Bao_cao.pdf dựa trên Bộ Tiêu Chí Rà Soát, tìm cho tôi các lỗi sai logic và tính toán lại bảng biểu."

6. Bảo Trì Hệ Thống Hàng Tuần

Vào mỗi chiều thứ Sáu, hãy nhắn cho AI câu lệnh sau:

"Hãy chạy quy trình dọn dẹp hệ thống."
